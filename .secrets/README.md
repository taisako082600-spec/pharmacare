# .secrets/

サービスアカウント鍵などの秘密情報を置く場所。**このフォルダの中身はGitに入りません**
（`.gitignore` で除外済み。このREADMEだけは追跡されます）。

## なぜここに置くのか

以前は鍵を `C:\Users\OWNER\Downloads\` に置いていましたが、Windowsの
**ストレージセンサー**が「ダウンロードフォルダー内で14日間開かれていないファイルを
自動削除する」設定になっており、鍵が消えてデプロイが一切できなくなりました
（2026-08-16）。ごみ箱も経由しないため復元もできません。

プロジェクト配下のこのフォルダは自動削除の対象外なので、ここに置けば消えません。

## 置くファイル

| ファイル名 | 用途 |
|---|---|
| `firebase-adminsdk.json` | Firebase Admin SDK のサービスアカウント鍵 |

鍵は必須ではありません。無い場合は `gcloud auth login` のログイン情報が
自動的に使われます（`auth_helper.js` 参照）。
